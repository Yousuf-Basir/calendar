Prompt: Create a finished square raster app icon for a minimal mobile calendar app named Calendar. Flat graphic, extremely simple, crisp clean silhouette: a near-black outlined calendar page with two short binding tabs and a single solid orange circular date marker centered within the lower page. Warm gray solid full-bleed background #dedbd5, near-black #1d1e1b, orange #fa633b. Icon mark centered entirely within the central 65% of the square, generous safe padding for circular and rounded OS masks. No words, no letters, no numbers, no emoji, no shadows, no gradients, no texture, no mockup, no rounded outer tile, no extra decorative dots. Output a square image intended as actual production PWA launcher art.

The raster output is resized and exported as indexed PNG with Sharp; no runtime image library is required. Versioned icon filenames and the service-worker cache change allow browsers to discover the new images. Existing installed launcher icons may take time to refresh depending on the browser/OS.
